# Visualizer: moved to its own project, Particle Accelerator

**2026-10-03, the owner:** the visualizer planned here is now a project of its own, **Particle Accelerator** (a separate repo, beside this one in the owner's `~/Developer` folder). It's built and used on its own first. When it's ready, Music Organizer adds it as a Swift package. The full plan, the visuals, the quality tiers and the measurements live there:

- `docs/PLAN.md`: the roadmap, and why it's built on Apple's Metal rather than Unreal Engine
- `docs/VISUALS.md`: one card per reference picture
- `docs/OUTPUT.md`: quality tiers from the 2019 iMac to a Mac Studio, with measurements
- `docs/INTEGRATION.md`: exactly how Music Organizer adds it

## What Music Organizer will do, when Particle Accelerator reaches 1.0

1. Add the package to `app/Package.swift`: one dependency line, and the product added to the `MusicOrganizer` target.
2. On the Local Visualizer page, add **Visualizer** beside Cover and Video. It shows `AcceleratorView` with the app's player (`Player.screen`), the playing song's cover, and the visualizer settings.
3. Keep those settings with the app's own (UserDefaults), and put the library's settings panel in Settings.

Nothing else changes: the visualizer only listens to the player, and writes no files. The app's rule that it never writes inside the library is untouched.

**One thing to settle first:** this repo is public, so its CI must be able to fetch Particle Accelerator. That means Particle Accelerator is public on GitHub too, or Music Organizer keeps a copy of it.
